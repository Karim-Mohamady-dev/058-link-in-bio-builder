# Linkly — منشئ صفحة الروابط (058)

منشئ صفحة روابط شخصية ثنائي اللغة (العربية RTL والإنجليزية LTR) مع معاينة مباشرة.

## المميزات
- تحرير الملف الشخصي: الاسم، اسم المستخدم، النبذة، لون الصورة الرمزية.
- إضافة روابط وتعديلها وحذفها وإعادة ترتيبها وإظهارها أو إخفائها، مع التحقق من العناوين.
- أربع سمات للصفحة وحسابات اجتماعية (إنستغرام، إكس، يوتيوب).
- معاينة مباشرة على شكل هاتف، ونسخ عنوان الصفحة.
- تحليلات تجريبية موسومة كبيانات عينة: المشاهدات والنقرات ومعدل النقر.
- حفظ تلقائي في localStorage، وحفظ تفضيل اللغة.

## التشغيل
```bash
npm install
npm run dev
npm run build
```

## ملاحظات
- عرض تجريبي محلي فقط؛ لا تُنشر الصفحات على الويب، ولا تُرسل بيانات إلى أي خادم.
